# SubTrack — Subscription Tracker App

> Never miss a renewal. Track all your subscriptions with smart reminders.

A production-ready React Native (Expo) mobile application built with TypeScript, Zustand, React Hook Form, and Expo Notifications.

---

## 📱 Features

- **Dashboard** — Monthly spending, upcoming & overdue renewals
- **Add/Edit/Delete** subscriptions with full form validation
- **Local Notifications** — Reminders before renewal date
- **Statistics** — Monthly/Yearly totals + category pie chart
- **Settings** — Dark/light theme, currency, notification toggle
- **Offline-first** — All data persisted via AsyncStorage
- **Dark & Light themes** with system-preference support

## 🚀 Setup (Linux)

### Prerequisites

```bash
# Install Node.js 18+ (via nvm recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 18
nvm use 18

# Install Expo CLI globally
npm install -g expo-cli
```

### Install & Run

```bash
# Clone / open the project
cd /path/to/Subscription-tracker

# Install dependencies (already done if you scaffolded this)
npm install

# Start Expo dev server
npx expo start
```

## 📱 Run on Android

### Option 1 — Physical Device (Easiest)

1. Install the **Expo Go** app from Google Play Store
2. Run `npx expo start`
3. Scan the QR code shown in terminal

### Option 2 — Android Emulator

```bash
# Install Android Studio: https://developer.android.com/studio
# Then set up an AVD (Android Virtual Device)

# Set ANDROID_HOME in ~/.bashrc
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/tools
export PATH=$PATH:$ANDROID_HOME/platform-tools

source ~/.bashrc

# Start emulator
emulator -avd Pixel_6_API_34  # replace with your AVD name

# Then run
npx expo start --android
```

### Option 3 — USB Debugging

```bash
# Enable Developer Options + USB Debugging on your phone
adb devices          # verify device is listed
npx expo start --android
```

## 📦 Build APK

### Method 1 — EAS Build (Recommended)

```bash
# Install EAS CLI
npm install -g eas-cli

# Login to Expo account (free)
eas login

# Initialize EAS in project (first time only)
eas build:configure

# Build a preview APK (unsigned, installable via ADB)
eas build --platform android --profile preview

# Build production AAB (for Play Store)
eas build --platform android --profile production
```

**EAS profiles** are defined in `eas.json` (auto-generated by `eas build:configure`).

### Method 2 — Local APK (requires Android SDK)

```bash
# Install expo-dev-client
npx expo install expo-dev-client

# Build locally
eas build --local --platform android --profile preview
```

## 🏪 Play Store Release Preparation

### Step 1 — Create Production Build
```bash
eas build --platform android --profile production
# This outputs a signed .aab file
```

### Step 2 — Google Play Console
1. Create account at [play.google.com/console](https://play.google.com/console)
2. Create a new app → Upload the `.aab` file
3. Fill in Store Listing (screenshots, description, icon)
4. Set Content Rating
5. Submit for review

### Step 3 — App Signing
EAS handles app signing automatically. Keys are stored securely in Expo's servers.

To use your own keystore:
```bash
eas credentials  # manage keystores interactively
```

## 🎨 Theming

Colors are defined in `src/constants/colors.ts` with separate `LightColors` and `DarkColors` palettes. Use the `useTheme()` hook anywhere:

```tsx
const { colors, isDark } = useTheme();
// colors.primary, colors.background, colors.text, etc.
```

Toggle theme via Settings → Dark Mode switch (persisted to AsyncStorage).

## 🔔 Notifications

- Powered by **Expo Notifications**
- Permission requested automatically on first launch (if enabled in settings)
- Each subscription schedules a notification `reminderDays` before renewal at **9:00 AM**
- Notifications are cancelled/rescheduled automatically on edit/delete
